# CollabFlow

CollabFlow is a modern, collaborative project management web application designed for agile and small teams to manage projects, assign tasks, collaborate on Kanban boards, track real-time progress, and streamline discussions.

 This is a team project management platform that tracks not only tasks, but also the **actual work and evidence** behind them.

A team member can:

* Receive and work on tasks
* Update progress and report blockers
* Submit GitHub commits or Pull Requests as evidence
* Send the work for manager review

The manager can review the work, request changes, or approve it. The system then calculates **accountability and team performance** and provides real-time notifications.

### Kanban Board

The Kanban board provides a visual way to track the progress of tasks.

Tasks move through different stages:

**TODO → IN PROGRESS → REVIEW → DONE**

* **Todo** – Task has not started.
* **In Progress** – Team member is currently working on it.
* **Review** – Work has been submitted and is waiting for manager review.
* **Done** – Work has been reviewed and approved.

If changes are required, the task can move back to **In Progress** and then be submitted again for review.

This makes the complete task lifecycle visible to both developers and managers.

The main achievement of CollabFlow is that it moves beyond "I completed my task" to "Here is the work evidence, it was verified, reviewed, and approved."
